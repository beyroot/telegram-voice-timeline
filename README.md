# Voice Timeline

Interactive voice-message navigation for Telegram-inspired interfaces.

**Functional prototype:** Web implementation with searchable timestamped transcript, seekable waveform and playback controls. SwiftUI source is included as a separate integration prototype.

**Status:** The web prototype was demonstrated in Safari on an iPhone. Native iOS compilation, automatic speech transcription, AI summarization and official Telegram integration are not validated or included.

The complete source will be committed in subsequent files. See the project docs for setup instructions.
