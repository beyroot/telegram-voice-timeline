# Suggested demo sequence

1. Show the expanded voice message and start playback.
2. Scrub to a later moment and show the updated active transcript segment.
3. Tap a timestamp to seek into the message.
4. Type `Acc` into search; show matching segments and jump to one.
5. Clear the search and type `Tele`; jump to the matching sentence.
6. Change playback speed from 1× to 1.5×.

Use the real Safari-on-iPhone screen recording. Do not label this as a native iOS recording.
