# Scope and known limitations

The web implementation is a functional, interactive prototype, not a static mockup.

- Audio playback needs the separately distributed example file at media/original-voice-message.m4a.
- Segments have manually edited, approximate timestamps; no speech recognition or automated alignment is performed.
- The overview is editorial, not AI generated.
- iOS source is unverified against Xcode compilation and needs the example audio bundled to play.
- Integration into the Telegram client, services and Telegram-specific APIs has not been implemented.
- A browser screen recording on an iPhone documents the web implementation, not the native SwiftUI implementation.
