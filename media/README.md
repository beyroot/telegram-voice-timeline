# Demonstration audio

The original 1:43 personal voice recording is intentionally not mirrored in this public source repository. To reproduce the original demonstration, place the supplied `original-voice-message.m4a` at `media/original-voice-message.m4a` and also at `ios/VoiceTimeline/original-voice-message.m4a` for the Xcode build. The complete downloadable submission package contains the recording. These are demo assets, not application source code.
